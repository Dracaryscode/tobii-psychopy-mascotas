# Estímulos

Las imágenes no se suben a GitHub. Cópialas aquí desde la carpeta de la investigadora:

| Origen (`Salidas_mascotas/F12_estimulos_finales_v5/`) | Destino |
|---|---|
| `png/` (36 PNG `MCv2_..._v5.png` y `estimulos_manifiesto.csv`) | `estimulos/experimentales/` |
| `practica/` (`MCpractica_conejo_lisa_v5.png`, `MCpractica_conejo_rayas_v5.png`) | `estimulos/practica/` |

Después ejecuta `python run.py verificar`. Si falta un archivo, una huella SHA-256 no coincide o un tamaño no es 592 × 1073 px, el programa se detiene y dice cuál.

No uses las versiones v1 a v4, ni la carpeta `svg/` (solo es un respaldo editable).
